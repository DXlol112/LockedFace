# Модуль `start_page.py`

## Назначение модуля

`script/UI/start_page.py` содержит стартовый экран LockedFace. Он показывает
рекомендации по расположению камеры и освещению, а затем передаёт управление
главному окну через callback продолжения.

## Место в UI-архитектуре

`MainWindow` создаёт страницу первой и регистрирует её в `QStackedWidget`:

```python
StartPage(self.go_to_main)
```

Страница не переключает `QStackedWidget` самостоятельно. Она только вызывает
полученную функцию `on_continue`; в текущем приложении это
`MainWindow.go_to_main()`.

## Зависимости

Модуль использует только PyQt6:

- `QWidget` как базовый класс страницы;
- `QVBoxLayout` для вертикального расположения элементов;
- `QLabel` для заголовка и инструкции;
- `QPushButton` для перехода дальше;
- `Qt` для выравнивания;
- `QEvent` для реакции на смену языка.

Доступ к конфигурации, камере и мониторингу на этой странице отсутствует.

## Класс `StartPage`

`StartPage(QWidget)` — простая страница без собственного изменяемого состояния.
Её публично значимые атрибуты — созданные виджеты:

| Атрибут | Тип | Назначение |
| --- | --- | --- |
| `text_title` | `QLabel` | Заголовок инструкции |
| `text` | `QLabel` | Основной текст рекомендации |
| `continue_button` | `QPushButton` | Переход к главной странице |

## Конструктор и жизненный цикл

Страница создаётся один раз при инициализации `MainWindow` и остаётся в
`QStackedWidget` до закрытия приложения. Повторное создание при возврате на
другие страницы не выполняется.

## Справочник методов

### `__init__(on_continue) -> None`

Создаёт вертикальный layout, два текстовых блока и кнопку продолжения.

**Параметры:**

- `on_continue` — вызываемый объект без аргументов. Он подключается к сигналу
  `continue_button.clicked`.

**Возвращаемое значение:** отсутствует.

**Изменение состояния:** создаёт `text_title`, `text` и `continue_button` как
атрибуты экземпляра.

**Побочные эффекты:** подключает Qt-сигнал кнопки к внешнему callback и вызывает
`retranslate_ui()` для начального заполнения текста.

**Важные условия:** переданный callback должен допускать вызов без аргументов.
Возвращаемое им значение не используется.

### `retranslate_ui() -> None`

Устанавливает все пользовательские строки страницы через `self.tr(...)`:
заголовок, рекомендацию по камере и текст кнопки.

**Параметры:** отсутствуют.

**Возвращаемое значение:** отсутствует.

**Изменение состояния:** меняет текст трёх виджетов.

**Побочные эффекты:** геометрия может быть пересчитана Qt, если перевод имеет
другую длину.

**Важные условия:** метод вызывается после создания всех текстовых виджетов и
повторно при событии смены языка.

### `changeEvent(event: QEvent) -> None`

Переопределяет стандартный обработчик QWidget. Если тип события равен
`QEvent.Type.LanguageChange`, вызывает `retranslate_ui()`.

**Параметры:**

- `event` — событие Qt, переданное фреймворком.

**Возвращаемое значение:** отсутствует.

**Изменение состояния:** при смене языка обновляет текст страницы.

**Побочные эффекты:** после собственной обработки всегда передаёт событие в
`super().changeEvent(event)`.

**Важные условия:** прямой вызов из прикладного кода обычно не требуется — Qt
отправляет событие после установки или удаления `QTranslator`.

## Сигналы, callbacks и поток данных

```text
Пользователь нажимает continue_button
        ↓ clicked
on_continue()
        ↓
MainWindow.go_to_main()
        ↓
QStackedWidget показывает MainPage
```

Страница ничего не передаёт callback и не сохраняет факт прохождения
инструкции.

## Как изменять и расширять модуль

### Добавить ещё один текстовый блок

1. Создайте `QLabel` в `__init__()`.
2. Настройте выравнивание и добавьте виджет в `layout` в нужном порядке.
3. Присваивайте переводимый текст в `retranslate_ui()`, а не только в
   конструкторе.
4. При добавлении `objectName` согласуйте его с QSS.

### Изменить действие кнопки

Предпочтительно передать другой callback при создании страницы. Если кнопке
нужны данные, следует определить явный контракт callback или собственный Qt-
сигнал, а затем обновить место создания `StartPage` в `MainWindow`.

### Добавить вторую кнопку

Создайте отдельный callback-параметр конструктора, подключите его к новой
кнопке и добавьте текст кнопки в `retranslate_ui()`. Не импортируйте
`MainWindow` внутрь модуля: это создаст циклическую зависимость и свяжет
страницу с конкретной навигацией.

## Связь со стилями

Стартовая страница использует общую таблицу `script/style/start_page.qss`.
Важные имена объектов:

- `text_title` у заголовка;
- `text` у инструкции;
- `continue_btn` у кнопки.

При изменении этих строк нужно проверить одноимённые QSS-селекторы.

## Текущие ограничения

- Страница не запоминает, видел ли пользователь инструкцию ранее.
- Callback не имеет статически описанного типа.
- Текст и расположение элементов задаются непосредственно в Python-коде.
- На странице нет отдельной кнопки возврата или закрытия.
