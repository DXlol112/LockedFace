# Модуль `file_card_widget.py`

## Назначение модуля

`script/UI/support_UI/file_card_widget.py` содержит `FileCard` — карточку одного
медиафайла в галерее. Она показывает статическое превью, кратко воспроизводит
GIF или MP4 при наведении, сообщает родительской странице о выборе и умеет
освобождать мультимедийные ресурсы перед удалением файла.

## Место в UI-архитектуре

`FilePage.refresh_gallery()` создаёт карточку для каждого файла в управляемом
каталоге:

```python
FileCard(str(path), self.select_file)
```

Карточка не читает и не сохраняет конфигурацию. При нажатии она передаёт путь
в callback, а `FilePage` обновляет общий выбор.

## Зависимости

### PyQt6 Multimedia

- `QMediaPlayer`, `QAudioOutput` и `QVideoWidget` воспроизводят MP4;
- `QVideoSink` получает отдельный кадр для статического превью;
- `QMovie` загружает и анимирует GIF;
- `QTimer` ограничивает hover-воспроизведение MP4 пятью секундами;
- `QPixmap` отображает изображения и извлечённый видеокадр.

Аудиовыход карточки всегда заглушён: галерея не должна воспроизводить звук.

## Класс `FileCard`

### Состояние карточки

| Атрибут | Назначение |
| --- | --- |
| `path` | Строковый путь медиафайла |
| `on_click` | Callback выбора, принимающий путь |
| `stack` | Переключает статическое превью и `QVideoWidget` |
| `preview_label` | Изображение, кадр видео или текст загрузки |
| `video_widget` | Поверхность hover-воспроизведения MP4 |
| `media_player` | Плеер MP4 |
| `audio_output` | Заглушённый аудиовыход |
| `sink` | Получатель первого кадра для превью MP4 |
| `movie` | `QMovie` для GIF или `None` |
| `stop_timer` | Одноразовая остановка MP4 через 5000 мс |
| `name_label` | Имя файла под превью |

Карточка имеет фиксированный размер `150 × 180`, а область превью —
`130 × 130`.

## Конструктор и жизненный цикл

После создания карточка сразу настраивает мультимедийные объекты и вызывает
`setup_preview()`. Для MP4 это может кратковременно запустить плеер, чтобы
получить кадр. При наведении карточка включает анимацию или видео, а при уходе
мыши останавливает их. Перед удалением файла `FilePage` вызывает
`cleanup_resources()`.

## Справочник методов

### `__init__(path: str, on_click) -> None`

Создаёт карточку, стек превью, мультимедийный плеер, таймер и подпись имени.

**Параметры:**

- `path` — путь отображаемого файла;
- `on_click` — callback, принимающий этот путь.

**Возвращаемое значение:** отсутствует.

**Изменение состояния:** создаёт все атрибуты таблицы выше и устанавливает
`movie = None`.

**Побочные эффекты:** создаёт мультимедийные ресурсы, заглушает аудио,
подключает сигналы статуса и таймера, вызывает `setup_preview()`.

### `setup_preview() -> None`

Выбирает способ превью по расширению файла в нижнем регистре.

**Изображения `.png`, `.jpg`, `.jpeg`, `.webp`:** загружаются напрямую в
`QPixmap`.

**GIF:** создаётся `QMovie`, масштабируется до размера стека, запускается и
сразу ставится на паузу, чтобы был виден первый кадр.

**MP4:** показывается текст «Загрузка…», `media_player` переключается на
`QVideoSink`, подключаются сигналы длительности и кадра, устанавливается
источник и запускается воспроизведение.

**Изменение состояния:** может создать `movie`, установить pixmap, текст или
источник плеера.

**Побочные эффекты:** для MP4 начинает фоновую загрузку и декодирование без
звука.

**Важные условия:** неизвестное расширение не получает специального превью.

### `_handle_media_status(status: QMediaPlayer.MediaStatus) -> None`

Если плеер сообщает `EndOfMedia`, перематывает MP4 в начало и снова запускает
воспроизведение.

**Побочные эффекты:** создаёт циклическое воспроизведение, пока плеер активен.

### `_seek_to_random_for_preview(duration: int) -> None`

После получения положительной длительности выбирает случайную позицию от
начала до последней секунды файла.

**Параметры:**

- `duration` — длительность медиа в миллисекундах.

**Изменение состояния:** меняет позицию `media_player`.

**Побочные эффекты:** отключает себя от `durationChanged`, чтобы случайная
позиция выбиралась только один раз. `TypeError` при уже отсутствующем
соединении игнорируется.

**Важные условия:** при `duration <= 0` метод завершает работу и остаётся
подключённым, ожидая корректное значение.

### `_on_video_frame_changed(frame) -> None`

Получает кадр через `QVideoSink`, преобразует его в `QImage`, а затем в
масштабированный `QPixmap` для статического превью.

**Параметры:** объект видеокадра Qt с методом `toImage()`.

**Изменение состояния:** при непустом изображении меняет pixmap
`preview_label`.

**Побочные эффекты:** отключает обработчик от `videoFrameChanged`, возвращает
плеер в начало и останавливает его.

**Важные условия:** используется только первый подходящий кадр после
подключения.

### `enterEvent(event) -> None`

Обрабатывает наведение мыши.

**GIF:** снимает паузу с `QMovie`.

**MP4:** переключает стек на `video_widget`, назначает его видеовыходом,
перематывает файл, запускает плеер и таймер остановки на пять секунд.

**Побочные эффекты:** начинает анимацию или декодирование; затем передаёт
событие базовому QFrame.

### `leaveEvent(event) -> None`

Вызывает `stop_media()` и передаёт событие базовому классу. Это останавливает
hover-превью сразу после ухода указателя.

### `stop_media() -> None`

Ставит GIF на паузу либо останавливает MP4 и возвращает стек к
`preview_label`.

**Изменение состояния:** меняет состояние `movie`, `media_player` и текущий
виджет `stack`.

**Важные условия:** для статичных изображений и неизвестных расширений метод
ничего не делает.

### `mousePressEvent(event) -> None`

При нажатии левой кнопкой вызывает `on_click(self.path)`.

**Побочные эффекты:** внешний callback обычно меняет рамки карточек и сохраняет
`selected_file` через `FilePage.select_file()`.

**Важные условия:** остальные кнопки мыши игнорируются. Метод не вызывает
реализацию базового класса.

### `set_selected(is_selected: bool) -> None`

Задаёт inline-стиль карточки: зелёная рамка толщиной три пикселя для выбранной
и серая рамка толщиной один пиксель для остальных.

**Параметры:** `is_selected` — новое визуальное состояние.

**Изменение состояния:** меняет stylesheet карточки, но не хранит отдельный
boolean-флаг.

### `cleanup_resources() -> None`

Останавливает текущее превью, очищает источник `media_player`, останавливает
`QMovie` и сбрасывает `movie = None`.

**Побочные эффекты:** освобождает файловые дескрипторы и мультимедийные ресурсы,
что позволяет удалить файл в Windows.

**Ошибки:** `RuntimeError` от уже уничтоженных Qt-объектов перехватывается и
записывается в лог.

### `changeEvent(event: QEvent) -> None`

При смене языка проверяет, содержит ли `preview_label` текст. Если содержит,
устанавливает переведённую строку «Загрузка…», затем передаёт событие базовому
классу.

**Важные условия:** метод не меняет подпись имени файла и не влияет на pixmap.

## Сигналы, callbacks и поток данных

```text
создание MP4-карточки
    → media_player.durationChanged
    → _seek_to_random_for_preview(duration)
    → sink.videoFrameChanged
    → _on_video_frame_changed(frame)
    → статический preview_label

наведение на MP4
    → enterEvent()
    → video_widget + media_player.play()
    → stop_timer.timeout или leaveEvent()
    → stop_media()

левая кнопка мыши
    → mousePressEvent()
    → on_click(path)
    → FilePage.select_file(path)
```

## Как изменять и расширять модуль

### Добавить новый формат изображения

Добавьте расширение в ветку статичных изображений `setup_preview()` и в
фильтр `FilePage.open_system_dialog()`. Убедитесь, что `QPixmap` действительно
поддерживает формат в целевом окружении.

### Добавить новый видеоформат

Потребуется обновить как минимум `setup_preview()`, `enterEvent()`,
`stop_media()` и фильтр страницы файлов. Также проверьте поддержку формата в
`VideoThread`, потому что галерея и предупреждающее воспроизведение используют
разные мультимедийные механизмы.

### Изменить длительность hover-превью

Измените аргумент `stop_timer.start(5000)` в `enterEvent()`. Значение задаётся в
миллисекундах.

### Добавить визуальное состояние

Если состояний становится больше, чем «выбрана/не выбрана», лучше хранить их
явно и формировать стиль централизованно. Сейчас каждый вызов
`set_selected()` полностью заменяет inline-stиль карточки.

## Связь со стилями

Карточка использует `objectName = "file_card"`; этот селектор также временно
переопределяется страницей файлов при подтверждении удаления. Подпись имени
получает небольшой inline-стиль без рамки. Подробное описание QSS в эту
страницу не входит.

## Текущие ограничения

- Размер карточки и превью фиксирован.
- Для MP4 создаётся отдельный плеер на каждую карточку, что может быть затратно
  при большой галерее.
- Извлечение случайного кадра зависит от мультимедийного backend Qt.
- Неизвестные расширения создают карточку без содержательного превью.
- `set_selected()` хранит состояние только визуально.
- Callback нажатия не типизирован.
