# Модуль `win_dialog.py`

## Назначение модуля

`script/UI/support_UI/win_dialog.py` реализует модальное перекрытие поверх
родительского виджета. Оно используется для ошибок, результатов проверки
обновлений и сообщений со ссылкой. В том же модуле находится кнопка
`WrappingPushButton`, способная переносить длинный текст и рассчитывать высоту
по доступной ширине.

## Место в UI-архитектуре

`MainPage`, `SettingsPage` и `FilePage` создают `WinDialog` как дочерний виджет
текущей страницы. Отдельное сохранение ссылки обычно не требуется: Qt владеет
дочерним объектом, а сам диалог показывает себя в конструкторе.

`WinDialog` наследует `QWidget`, а не `QDialog`. Модальность создаётся
визуальным overlay, который занимает прямоугольник родителя и перехватывает
мышь.

## Зависимости

- `QStylePainter`, `QStyleOptionButton` и `QStyle` обеспечивают нативную
  отрисовку кнопки без стандартного однострочного текста;
- `QDesktopServices` и `QUrl` открывают внешнюю ссылку;
- `QSizePolicy` и метрики шрифта участвуют в расчёте размеров;
- `Path` загружает `script/style/QSS_support_UI/win_dialog.qss`;
- стандартный `logging` сообщает о проблеме чтения стиля.

## Класс `WrappingPushButton`

Класс наследует `QPushButton`. Он просит layout учитывать высоту для заданной
ширины, а текст рисует вручную с `TextWordWrap` и `TextWrapAnywhere`.

### Константы класса

| Константа | Значение | Назначение |
| --- | --- | --- |
| `_HORIZONTAL_PADDING` | `32` | Горизонтальные внутренние отступы |
| `_VERTICAL_PADDING` | `16` | Вертикальные внутренние отступы |
| `_MINIMUM_WIDTH` | `120` | Предпочтительная минимальная ширина |

## Справочник методов `WrappingPushButton`

### `__init__(text: str, parent: QWidget | None = None) -> None`

Передаёт текст и родителя базовому `QPushButton`, затем задаёт политику размера
`Preferred` по ширине и `Minimum` по высоте.

**Параметры:** стандартные текст кнопки и необязательный родитель.

**Изменение состояния:** меняет `QSizePolicy`.

### `_text_flags() -> int`

Статический метод возвращает числовую комбинацию флагов выравнивания по
центру, переноса по словам и переноса длинных непрерывных строк.

**Параметры и побочные эффекты:** отсутствуют.

### `_text_height(width: int) -> int`

Вычитает горизонтальные отступы из ширины и через
`fontMetrics().boundingRect()` вычисляет высоту перенесённого текста.

**Параметры:** `width` — полная доступная ширина кнопки.

**Возвращаемое значение:** высота границ текста в пикселях.

**Важные условия:** ширина текста ограничивается снизу единицей, а расчётная
высота прямоугольника — `10_000` пикселей.

### `hasHeightForWidth() -> bool`

Всегда возвращает `True`, сообщая layout-системе Qt, что предпочтительная
высота зависит от выделенной ширины.

### `heightForWidth(width: int) -> int`

Возвращает максимальное из однострочной высоты шрифта и высоты перенесённого
текста, затем добавляет вертикальные отступы.

**Побочные эффекты:** отсутствуют.

### `sizeHint() -> QSize`

Вычисляет естественную ширину по длине текста и горизонтальным отступам,
ограничивает её минимумом класса и `maximumWidth()`, затем рассчитывает
соответствующую высоту.

**Возвращаемое значение:** предпочтительный `QSize`.

### `minimumSizeHint() -> QSize`

Выбирает ширину как минимум из `_MINIMUM_WIDTH` и `maximumWidth()`, после чего
возвращает размер с высотой от `heightForWidth()`.

### `paintEvent(event: QPaintEvent) -> None`

Самостоятельно рисует кнопку с переносимым текстом.

**Алгоритм:**

1. создаёт и заполняет `QStyleOptionButton`;
2. временно удаляет стандартный текст из style option;
3. рисует стандартный фон и рамку кнопки;
4. получает прямоугольник содержимого;
5. выбирает цвет текста из palette;
6. рисует сохранённый текст с флагами `_text_flags()`.

**Побочные эффекты:** полностью заменяет стандартную отрисовку текста кнопки,
сохраняя нативный внешний вид остальных элементов.

**Важные условия:** параметр `event` намеренно не используется.

## Класс `WinDialog`

### Состояние диалога

| Атрибут | Назначение |
| --- | --- |
| `_button_url` | URL необязательной кнопки действия |
| `dialog` | Центральная панель сообщения |
| `title_label` | Заголовок |
| `close_button` | Кнопка `×` |
| `message_label` | Переносимое сообщение в формате plain text |
| `open_button` | `WrappingPushButton` или `None` |

## Конструктор и жизненный цикл `WinDialog`

Весь жизненный цикл начинается в конструкторе: overlay получает размер
родителя, центральная панель строится и центрируется, после чего виджет
поднимается и показывается. Закрытие выполняется через `hide()` и
`deleteLater()`.

## Справочник методов `WinDialog`

### `__init__(parent, message, _open_button=False, text_open_button=None, title=None, button_url=...) -> None`

Создаёт и сразу показывает модальное перекрытие.

**Параметры:**

- `parent: QWidget` — страница, которую должен перекрыть диалог;
- `message: str` — основной текст;
- `_open_button: bool` — создавать ли кнопку открытия ссылки;
- `text_open_button: str | None` — пользовательский текст кнопки или
  переводимое «Открыть»;
- `title: str | None` — заголовок или переводимое «Сообщение»;
- `button_url: str` — URL действия; по умолчанию страница последнего релиза.

**Изменение состояния:** создаёт все элементы диалога и сохраняет URL.

**Побочные эффекты:** загружает QSS, подключает кнопки, рассчитывает размеры,
центрирует overlay, поднимает и показывает его.

**Важные условия:** сообщение принудительно отображается как `PlainText`,
поэтому HTML-разметка в нём не интерпретируется. Ширина центральной панели
ограничена диапазоном от `280` до `400` пикселей с учётом ширины родителя.

### `_center_dialog() -> None`

Получает прямоугольник родительского виджета и перемещает центральную панель по
горизонтали и вертикали в его центр.

**Изменение состояния:** меняет позицию `dialog`.

**Важные условия:** метод предполагает наличие `parentWidget()`.

### `_load_stylesheet() -> None`

Читает `script/style/QSS_support_UI/win_dialog.qss` в UTF-8 и применяет содержимое ко всему
overlay.

**Побочные эффекты:** выполняет чтение файла и вызывает `setStyleSheet()`.

**Ошибки:** `OSError` не прерывает создание диалога, а записывается в лог.

### `mousePressEvent(event) -> None`

Если нажатие произошло за пределами `dialog.geometry()`, вызывает `_close()`.
После проверки передаёт событие базовому QWidget.

**Важные условия:** нажатия внутри центральной панели не закрывают окно, кроме
отдельной кнопки `×`.

### `_close() -> None`

Скрывает overlay и планирует удаление через `deleteLater()`.

**Побочные эффекты:** диалог перестаёт перехватывать события родителя и будет
уничтожен после возврата управления циклу событий Qt.

### `_open_url() -> None`

Проверяет `_button_url.isValid()` и передаёт допустимый URL в
`QDesktopServices.openUrl()`.

**Побочные эффекты:** запрашивает у операционной системы открытие браузера или
другого обработчика URL.

**Важные условия:** результат `openUrl()` не проверяется; при недопустимом URL
метод ничего не делает.

## Сигналы, callbacks и поток данных

```text
создание WinDialog(...)
    → _load_stylesheet()
    → adjustSize()
    → _center_dialog()
    → show()

close_button.clicked или клик вне панели
    → _close()
    → hide() + deleteLater()

open_button.clicked
    → _open_url()
    → QDesktopServices.openUrl(...)
```

У `WinDialog` нет пользовательских Qt-сигналов с результатом. Вызывающий код
не узнаёт, каким способом закрыто сообщение.

## Как изменять и расширять модуль

### Добавить новое действие

Для одного действия можно расширить существующий необязательный блок кнопки.
Если действий несколько или вызывающему коду нужен результат, лучше добавить
явные сигналы либо использовать `QDialog` с кодом завершения.

### Изменить правила закрытия

Логика клика вне панели находится в `mousePressEvent()`. Для клавиши Escape
нужно добавить обработку клавиатуры и обеспечить фокус overlay.

### Добавить динамическую смену языка

Сейчас тексты фиксируются при создании. Для живого перевода потребуется
сохранить исходные смысловые значения, реализовать `retranslate_ui()` и
обработать `LanguageChange`, как это делают страницы.

### Поддержать изменение размера родителя

Добавьте `resizeEvent()` у overlay: обновляйте его геометрию по
`parentWidget().rect()`, пересчитывайте допустимую ширину панели и снова
вызывайте `_center_dialog()`.

## Связь со стилями

Диалог самостоятельно загружает `script/style/QSS_support_UI/win_dialog.qss`. Основные
`objectName`: `overlay`, `modalDialog`, `titleLabel`, `closeButton`,
`messageLabel` и `openButton`. `WrappingPushButton` рисует фон через активный
Qt-стиль, поэтому остаётся совместимым с QSS кнопки.

## Текущие ограничения

- Это визуально модальный QWidget, а не системный `QDialog`.
- Overlay получает геометрию родителя только при создании.
- Клавиша Escape отдельно не обрабатывается.
- Динамическая смена языка не обновляет уже открытый диалог.
- Результат открытия внешнего URL не проверяется.
- URL последнего релиза задан значением параметра по умолчанию в коде.
