# Модуль `main_page.py`

## Назначение модуля

`script/UI/main_page.py` содержит главный рабочий экран LockedFace. Он отвечает
за выбор длительности сессии, предварительную проверку камеры и выбранного
файла, запуск фонового мониторинга, показ кадров камеры, паузу и остановку.

## Место в UI-архитектуре

`MainWindow` создаёт страницу с тремя callbacks:

```python
MainPage(
    on_start=self.start_program,
    on_settings=self.go_to_settings,
    on_file=self.go_to_file,
)
```

Внутри страницы есть два режима:

- `timer_widget` — настройка времени, переход к файлам и настройкам;
- `video_widget` — изображение с камеры и кнопки паузы и остановки.

Одновременно виден только один из этих контейнеров.

## Зависимости

### UI и мультимедиа

- PyQt6 создаёт виджеты, сигналы, анимацию и `QImage`/`QPixmap`.
- OpenCV проверяет доступ к камере и преобразует BGR-кадры в RGB.
- NumPy задаёт тип кадров, поступающих из рабочего потока.

### Внутренние зависимости

- `VideoThread` выполняет мониторинг вне главного UI-потока;
- `load_config()` читает время, файл и настройки распознавания;
- `update_config()` сохраняет длительность сессии;
- `WinDialog` показывает ошибки валидации;
- `__version__` используется в подписи версии.

## Класс `MainPage`

### Состояние страницы

| Атрибут | Назначение |
| --- | --- |
| `on_start_callback` | Уведомляет главное окно о фактическом запуске мониторинга |
| `on_settings` | Открывает страницу настроек |
| `on_file` | Открывает страницу файлов |
| `h`, `m`, `s` | Выбранное время, разделённое на часы, минуты и секунды |
| `thread` | Активный `VideoThread` или `None` |
| `timer_widget` | Контейнер настройки времени |
| `video_widget` | Контейнер кадра камеры и управляющих кнопок |
| `animation` | Текущая анимация переключения контейнеров |

Остальные атрибуты хранят кнопки, подписи и layout-элементы, к которым методы
обращаются после конструктора.

## Конструктор и жизненный цикл

При создании страница загружает ранее сохранённое время, строит оба режима,
скрывает `video_widget` и устанавливает переводимые подписи. Рабочий поток
создаётся только после успешной валидации. После завершения потока ссылка на
него сбрасывается в `None`, а страница возвращается к таймеру.

## Справочник методов

### `__init__(on_start, on_settings, on_file) -> None`

Инициализирует callbacks, время, состояние потока и оба контейнера страницы.

**Параметры:**

- `on_start` — callback без аргументов, вызываемый после запуска потока;
- `on_settings` — callback открытия настроек;
- `on_file` — callback открытия галереи файлов.

**Возвращаемое значение:** отсутствует.

**Изменение состояния:** создаёт все атрибуты страницы, загружает `h`, `m`,
`s`, устанавливает `thread = None`.

**Побочные эффекты:** читает пользовательскую конфигурацию и подключает
сигналы кнопок.

### `_setup_timer_ui() -> None`

Строит режим выбора времени: заголовок с кнопками файлов и настроек, три ряда
управления таймером, кнопку запуска, подсказку и версию.

**Параметры и результат:** отсутствуют.

**Изменение состояния:** создаёт `file_button`, `settings_button`,
`time_label`, `start_button`, `info_label`, `version_label` и связанные layout-
объекты.

**Побочные эффекты:** подключает навигационные callbacks и `start_clicked()`;
в конце обновляет отображение времени.

### `_setup_video_ui() -> None`

Строит режим активного мониторинга с `video_label`, `pause_button` и
`stop_button`.

**Параметры и результат:** отсутствуют.

**Изменение состояния:** создаёт виджеты режима видео.

**Побочные эффекты:** подключает `toggle_pause()` и `stop_video_manual()`.
Кнопки получают локальные inline-стили для круглой формы.

### `_load_time_from_config() -> None`

Читает `work_time_seconds`, преобразует значение в неотрицательное целое и
раскладывает его в `h`, `m`, `s`.

**Параметры и результат:** отсутствуют.

**Изменение состояния:** заменяет значения `h`, `m`, `s`.

**Побочные эффекты:** вызывает `load_config()`.

**Важные условия:** некорректный тип или строка заменяются нулём. Верхняя
граница сохранённого значения не применяется, поэтому в конфигурации могут
находиться часы больше `23`, хотя кнопки редактирования работают по модулю 24.

### `_save_time_to_config() -> None`

Сохраняет рассчитанную длительность под ключом `work_time_seconds`.

**Параметры и результат:** отсутствуют.

**Побочные эффекты:** вызывает `update_config()` и записывает конфигурацию.

### `_get_monitor_settings() -> tuple[str, bool, bool]`

Читает настройки, необходимые для запуска `VideoThread`.

**Возвращаемое значение:** кортеж `(file_path, gaze_enabled,
glasses_enabled)`. Отсутствующий путь превращается в пустую строку, флаги — в
`bool`.

**Побочные эффекты:** вызывает `load_config()`.

### `_create_arrow(text: str, callback) -> QPushButton`

Создаёт одну кнопку изменения времени.

**Параметры:**

- `text` — символ кнопки, сейчас `▲` или `▼`;
- `callback` — обработчик нажатия без аргументов.

**Возвращаемое значение:** настроенный `QPushButton`.

**Побочные эффекты:** задаёт `objectName = "arrow_btn"` и подключает сигнал
`clicked`.

### `_total_seconds() -> int`

Возвращает `h * 3600 + m * 60 + s`. Состояние не изменяет и внешних вызовов не
выполняет.

### `_update_time_label() -> None`

Форматирует текущее состояние как `HH:MM:SS` и записывает строку в
`time_label`.

**Изменение состояния:** меняет только текст label.

### `inc_h() -> None`

Увеличивает часы на один по модулю `24`, затем обновляет подпись. После `23`
получается `00`.

### `inc_m() -> None`

Увеличивает минуты на один по модулю `60`, затем обновляет подпись. Перенос в
часы не выполняется.

### `inc_s() -> None`

Увеличивает секунды на один по модулю `60`, затем обновляет подпись. Перенос в
минуты не выполняется.

### `dec_h() -> None`

Уменьшает часы на один по модулю `24`, затем обновляет подпись. Из `00`
получается `23`.

### `dec_m() -> None`

Уменьшает минуты на один по модулю `60`, затем обновляет подпись.

### `dec_s() -> None`

Уменьшает секунды на один по модулю `60`, затем обновляет подпись.

Методы изменения времени не сохраняют конфигурацию сразу. Сохранение
происходит при успешном запуске через `_save_time_to_config()`.

### `start_clicked() -> None`

Валидирует входные данные перед запуском.

**Проверки:**

1. `cv2.VideoCapture(0)` должен открыть камеру;
2. `selected_file` должен указывать на существующий файл;
3. выбранное время должно быть больше нуля.

**Изменение состояния:** при успехе сохраняет время; при ошибке состояние
мониторинга не меняется.

**Побочные эффекты:** кратковременно открывает камеру, освобождает её после
успешного открытия, читает конфигурацию, может показать `WinDialog`, записать
конфигурацию и начать анимацию.

**Важные условия:** все найденные ошибки объединяются через перевод строки и
показываются одним диалогом.

### `_animate_and_start() -> None`

Создаёт `QPropertyAnimation` для свойства `geometry` у `timer_widget` и за
500 мс сдвигает контейнер вниз на высоту страницы.

**Изменение состояния:** сохраняет анимацию в `self.animation`, чтобы объект не
был удалён сборщиком мусора.

**Побочные эффекты:** по сигналу `finished` вызывает
`_start_video_process()`.

### `_start_video_process() -> None`

Переключает страницу в режим видео и запускает рабочий поток.

**Изменение состояния:** скрывает `timer_widget`, показывает `video_widget`,
создаёт `self.thread`.

**Побочные эффекты:** повторно читает настройки, подключает сигналы потока,
вызывает `thread.start()` и затем `on_start_callback()`, если callback задан.

**Важные условия:** метод рассчитан на вызов после успешной валидации. Прямой
вызов может запустить поток с пустым файлом или нулевым временем.

### `update_video_image(cv_img: np.ndarray) -> None`

Qt-slot, принимающий BGR-кадр от `VideoThread`.

**Параметры:**

- `cv_img` — трёхканальный NumPy-массив кадра OpenCV.

**Возвращаемое значение:** отсутствует.

**Изменение состояния:** заменяет pixmap в `video_label`.

**Побочные эффекты:** преобразует BGR в RGB, создаёт `QImage`, затем масштабирует
`QPixmap` с сохранением пропорций до текущего размера label.

**Важные условия:** код ожидает массив формы `(height, width, channels)` и
формат, совместимый с `cv2.COLOR_BGR2RGB`.

### `toggle_pause() -> None`

Если поток существует, переключает его паузу через `VideoThread.toggle_pause()`
и меняет текст кнопки на «Продолжить» или «Пауза».

**Важные условия:** при `thread is None` метод завершается без действий.

### `stop_video_manual() -> None`

Если поток существует, вызывает `VideoThread.stop()`. Метод потока снимает флаг
выполнения и ожидает завершения через `wait()`.

**Побочные эффекты:** UI-поток может ожидать, пока рабочий поток освободит
камеру и медиа-ресурсы.

### `on_video_finished() -> None`

Обрабатывает `finished_signal` рабочего потока.

**Изменение состояния:** скрывает режим видео, показывает таймер, очищает кадр,
сбрасывает `thread = None` и возвращает текст кнопки паузы.

**Побочные эффекты:** создаёт обратную 500-миллисекундную анимацию появления
`timer_widget` снизу.

### `retranslate_ui() -> None`

Обновляет тексты запуска, подсказки, версии, остановки и паузы через
`self.tr(...)`. Вместо маркера `1.0.0` в переведённой строке версии подставляет
`__version__`.

**Изменение состояния:** меняет тексты пяти виджетов.

**Важные условия:** если поток поставлен на паузу во время смены языка, метод
безусловно устанавливает текст «Пауза», хотя состояние потока не меняется.

### `changeEvent(event: QEvent) -> None`

При `LanguageChange` вызывает `retranslate_ui()`, затем передаёт событие
базовому QWidget.

### `resizeEvent(event) -> None`

Изменяет размеры `timer_widget` и `video_widget` так, чтобы каждый занимал всю
страницу, затем вызывает реализацию базового класса.

**Побочные эффекты:** влияет на конечную геометрию последующих анимаций и размер
масштабирования кадров.

## Сигналы, callbacks и поток данных

```text
start_button.clicked
    → start_clicked()
    → проверка камеры, файла и времени
    → _animate_and_start()
    → _start_video_process()
    → VideoThread.start()

VideoThread.change_pixmap_signal(frame)
    → update_video_image(frame)

VideoThread.finished_signal()
    → on_video_finished()
```

Навигационные кнопки вызывают `on_file` и `on_settings` напрямую.

## Как изменять и расширять модуль

### Добавить новое условие запуска

Добавьте проверку в `start_clicked()`, сформируйте переводимое сообщение и
добавьте его в `errors`. Запуск должен продолжаться только при пустом списке.

### Добавить параметр мониторинга

1. Добавьте ключ и значение по умолчанию в конфигурацию.
2. Дайте пользователю изменить его в `SettingsPage`.
3. Прочитайте значение в `_get_monitor_settings()`.
4. Передайте его в конструктор `VideoThread`.
5. Обновите тип возвращаемого кортежа или замените кортеж именованной
   структурой, если параметров становится много.

### Изменить диапазон таймера

Согласованно измените модуль в `inc_*`/`dec_*`, формат `_update_time_label()` и
валидацию сохранённого значения в `_load_time_from_config()`.

### Изменить представление кадра

Изменения преобразования цвета и масштаба выполняются в
`update_video_image()`. Сохраняйте создание и изменение Qt-виджетов в главном
потоке; рабочий поток должен по-прежнему передавать данные сигналом.

## Связь со стилями

Большая часть страницы использует `script/style/main_page.qss`. Значимые
`objectName`: `header`, `icon_btn`, `arrow_btn`, `timer`, `start_btn`,
`text_info_file` и `ver`. Кнопки паузы и остановки дополнительно оформлены
inline-стилями в `_setup_video_ui()`.

## Текущие ограничения

- Камера всегда открывается по индексу `0`; выбора устройства в UI нет.
- Проверка камеры выполняется синхронно при нажатии «СТАРТ».
- Часы в интерактивном таймере ограничены диапазоном `00–23`.
- Перенос секунд в минуты и минут в часы не выполняется.
- Параметры callbacks и кадра частично не типизированы.
- `stop()` рабочего потока вызывается с ожиданием завершения, что потенциально
  может ненадолго заблокировать интерфейс.
