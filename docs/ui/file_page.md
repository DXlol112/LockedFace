# Модуль `file_page.py`

## Назначение модуля

`script/UI/file_page.py` реализует галерею пользовательских медиафайлов.
Страница копирует выбранные файлы в управляемый каталог LockedFace, строит для
них карточки, сохраняет текущий выбор и удаляет файлы после повторного
подтверждения.

## Место в UI-архитектуре

`MainWindow` создаёт страницу с callback возврата:

```python
FilePage(self.go_back)
```

`MainPage` открывает её через навигационный callback `on_file`. При возврате
`MainWindow.go_back()` сбрасывает режим подтверждения удаления, обновляет
галерею и показывает главную страницу.

Каждый файл отображается отдельным `FileCard`. Callback карточки связан с
`FilePage.select_file()`.

## Зависимости

### PyQt6 и файловая система

- `QFileDialog` открывает системный диалог выбора;
- `QScrollArea` и `QGridLayout` формируют прокручиваемую сетку;
- `Path` проверяет и нормализует пути;
- `shutil.copy2()` копирует файл с метаданными;
- `Path.unlink()` удаляет управляемый файл.

### Внутренние зависимости

- `get_media_dir()` возвращает пользовательский каталог медиа и создаёт его при
  необходимости;
- `load_config()` читает `selected_file`;
- `update_config()` сохраняет или очищает выбор;
- `FileCard` показывает превью и сообщает о нажатии;
- `WinDialog` отображает ошибки копирования и удаления.

## Класс `FilePage`

### Состояние страницы

| Атрибут | Тип | Назначение |
| --- | --- | --- |
| `confirm_delete` | `bool` | Ожидается ли повторное нажатие для удаления |
| `on_back` | callback | Возврат к главной странице |
| `selected_path` | `str \| None` | Нормализованный путь выбранного медиа |
| `cards` | `list[FileCard]` | Карточки текущего содержимого каталога |
| `grid` | `QGridLayout` | Сетка до четырёх карточек в строке |
| `add_file_button` | `QPushButton` | Открывает системный диалог |
| `delete_button` | `QPushButton` | Запускает или подтверждает удаление |

## Конструктор и жизненный цикл

Страница создаётся один раз. Конструктор проверяет сохранённый выбор, строит
заголовок, прокручиваемую сетку и нижние кнопки, устанавливает тексты и сразу
заполняет галерею.

Обновление галереи создаёт новые экземпляры `FileCard`. Удаление выбранного
файла предварительно освобождает его мультимедийные ресурсы.

## Справочник методов

### `__init__(on_back) -> None`

Инициализирует состояние и полностью строит страницу.

**Параметры:**

- `on_back` — callback без аргументов, подключаемый к кнопке возврата.

**Возвращаемое значение:** отсутствует.

**Изменение состояния:** задаёт `confirm_delete = False`, загружает
`selected_path`, создаёт пустой список `cards` и все виджеты.

**Побочные эффекты:** читает конфигурацию, создаёт каталог медиа при обращении к
нему, подключает сигналы и вызывает `refresh_gallery()`.

### `_load_selection() -> str | None`

Проверяет сохранённый `selected_file`.

**Возвращаемое значение:** абсолютный строковый путь, если файл существует и
находится внутри управляемого каталога; иначе `None`.

**Побочные эффекты:** читает конфигурацию и обращается к `get_media_dir()`.

**Важные условия:** недействительное значение не удаляется из конфигурации —
оно только игнорируется текущим экземпляром страницы.

### `_is_managed_media(path: Path) -> bool`

Проверяет, находится ли разрешённый путь внутри `get_media_dir()`.

**Параметры:**

- `path` — проверяемый путь.

**Возвращаемое значение:** `True`, если `path.resolve()` можно представить
относительно разрешённого каталога медиа; иначе `False`.

**Изменение состояния:** отсутствует.

**Побочные эффекты:** `get_media_dir()` может создать каталог.

**Важные условия:** метод проверяет границу каталога, но отдельно не проверяет,
что путь существует или является файлом.

### `_destination_for(source: Path) -> Path`

Подбирает свободное имя для копии файла в каталоге медиа.

**Алгоритм:** сначала используется исходное имя; при конфликте добавляется
` (1)`, ` (2)` и так далее перед расширением.

**Возвращаемое значение:** первый незанятый путь назначения.

**Побочные эффекты:** может создать каталог через `get_media_dir()`, но сам файл
не копирует.

### `open_system_dialog() -> None`

Открывает системный диалог с фильтром `png`, `jpg`, `jpeg`, `webp`, `mp4` и
`gif`, затем копирует выбранный файл в управляемый каталог.

**Изменение состояния:** после успеха обновляет галерею и делает новую копию
выбранной.

**Побочные эффекты:** открывает нативный диалог, вызывает `shutil.copy2()`,
создаёт карточки и сохраняет `selected_file` через `select_file()`.

**Ошибки:** `OSError` при копировании показывается через `WinDialog`; галерея и
выбор в этом случае не изменяются.

**Важные условия:** отмена диалога приводит к немедленному выходу. Файл всегда
копируется, а не используется напрямую по исходному пути.

### `refresh_gallery() -> None`

Полностью перестраивает сетку карточек по текущему содержимому каталога медиа.

**Алгоритм:**

1. извлекает старые элементы из `grid` и вызывает `deleteLater()` у виджетов;
2. очищает список `cards`;
3. получает все обычные файлы и сортирует их по имени без учёта регистра;
4. создаёт `FileCard` для каждого пути;
5. отмечает сохранённый путь зелёной рамкой;
6. размещает карточки по четыре в строке.

**Изменение состояния:** заменяет содержимое `cards` и `grid`.

**Побочные эффекты:** читает файловую систему и создаёт мультимедийные объекты
для превью.

### `select_file(path: str | Path) -> None`

Выбирает управляемый медиафайл.

**Параметры:** строковый или объектный путь.

**Изменение состояния:** сбрасывает подтверждение удаления, записывает
абсолютный путь в `selected_path` и обновляет рамки карточек.

**Побочные эффекты:** сохраняет `selected_file` через `update_config()`.

**Важные условия:** путь вне каталога медиа игнорируется. Существование файла
здесь повторно не проверяется.

### `delete_file() -> None`

Реализует удаление в два нажатия.

**Первое нажатие:**

- устанавливает `confirm_delete = True`;
- меняет текст кнопки на «Вы уверены?»;
- добавляет кнопке красный inline-стиль;
- выделяет выбранную карточку красной рамкой.

**Второе нажатие:**

- повторно проверяет границу управляемого каталога;
- вызывает `cleanup_resources()` у выбранной карточки;
- удаляет файл через `unlink(missing_ok=True)`;
- очищает `selected_path` и `selected_file`;
- сбрасывает кнопку и перестраивает галерею.

**Побочные эффекты:** удаляет пользовательскую копию файла из каталога
LockedFace и записывает конфигурацию.

**Ошибки:** `OSError` показывает `WinDialog`, после чего режим подтверждения
сбрасывается. Исходный файл, из которого пользователь добавлял копию, не
удаляется.

**Важные условия:** при отсутствии выбора метод ничего не делает.

### `reset_delete_button() -> None`

Отменяет режим подтверждения, возвращает обычный текст кнопки и очищает её
inline-стиль.

**Изменение состояния:** устанавливает `confirm_delete = False`.

**Важные условия:** метод не восстанавливает стиль карточки напрямую;
нормальная рамка возвращается при выборе другой карточки или перестроении
галереи.

### `retranslate_ui() -> None`

Устанавливает переводимый текст кнопки добавления и вызывает
`reset_delete_button()` для текста удаления.

**Побочные эффекты:** смена языка отменяет активное подтверждение удаления.

### `changeEvent(event: QEvent) -> None`

При событии `LanguageChange` вызывает `retranslate_ui()`, затем передаёт
событие базовому QWidget.

## Сигналы, callbacks и поток данных

```text
add_file_button.clicked
    → open_system_dialog()
    → copy2(source, managed_destination)
    → refresh_gallery()
    → select_file(destination)
    → update_config("user_settings", selected_file=...)

FileCard.mousePressEvent
    → on_click(card.path)
    → FilePage.select_file(path)

delete_button.clicked
    → delete_file()
    → первое нажатие: подтверждение
    → второе нажатие: cleanup → unlink → update_config → refresh
```

## Как изменять и расширять модуль

### Добавить новый разрешённый формат

1. Добавьте расширение в фильтр `QFileDialog`.
2. Реализуйте его превью в `FileCard.setup_preview()`.
3. Проверьте, что `VideoThread` умеет использовать формат как предупреждение.
4. Добавьте обработку hover и освобождение ресурсов, если формат использует
   плеер.

Одного изменения фильтра недостаточно: галерея покажет любой файл из каталога,
но не гарантирует корректное превью или воспроизведение мониторингом.

### Изменить число колонок

Измените оба выражения в `refresh_gallery()`:
`index // column_count` и `index % column_count`. Желательно вынести число
колонок в именованную константу.

### Добавить метаданные карточки

Передайте данные в расширенный конструктор `FileCard` либо позвольте карточке
самой прочитать их из `path`. Не сохраняйте временное состояние карточки в
`config.json`, если оно не должно переживать перезапуск.

### Изменить политику хранения файлов

Согласованно обновите `_is_managed_media()`, `_destination_for()`, загрузку
выбора и удаление. Проверку принадлежности управляемому каталогу убирать
нельзя: она защищает от удаления произвольного файла по значению из
конфигурации.

## Связь со стилями

Страница оформляется через `script/style/file_page.qss` и общие селекторы.
Основные `objectName`: `header_sett`, `back_btn`, `file_scroll`, `add_file_btn`
и `add_del_btn`. Красное подтверждение удаления устанавливается inline в
`delete_file()`.

## Текущие ограничения

- Галерея перечисляет все файлы в каталоге, не фильтруя их по расширению.
- Фильтр добавления включает `webp` и `gif`, но поддержка этих форматов в
  предупреждающем окне мониторинга отличается от поддержки превью.
- При каждом обновлении все карточки и превью создаются заново.
- Проверяется расширение, выбранное диалогом, но содержимое файла отдельно не
  валидируется.
- Недействительный `selected_file` игнорируется, но автоматически не удаляется
  из конфигурации.
