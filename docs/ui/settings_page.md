# Модуль `settings_page.py`

## Назначение модуля

`script/UI/settings_page.py` реализует экран настроек LockedFace. На нём
пользователь может проверить обновления, открыть каталог приложения или
репозиторий, сменить язык, включить отслеживание глаз, указать наличие очков и
раскрыть блок дополнительных настроек.

Модуль содержит два класса:

- `_MiniDropdown` — компактный выпадающий список с отдельными накладными
  элементами для выбранного значения и иконки;
- `SettingsPage` — сама страница настроек.

## Место в UI-архитектуре

`MainWindow` создаёт страницу и передаёт ей callback возврата:

```python
SettingsPage(self.go_back)
```

Страница сохраняет параметры сразу после изменения. `MainPage` читает их
позже, непосредственно перед созданием `VideoThread`. Смена языка применяется
к уже запущенному `QApplication` без перезапуска.

## Зависимости

### PyQt6

Виджеты и layout-классы формируют прокручиваемую страницу. `QDesktopServices`
и `QUrl` открывают локальный каталог и веб-ссылки. `QApplication.instance()`
нужен для применения языка к текущему приложению.

### Внутренние зависимости

- `load_config()` загружает сохранённые значения элементов управления;
- `update_config()` сохраняет новое значение сразу после изменения;
- `set_application_language()` устанавливает или удаляет `QTranslator`;
- `__version__` содержит текущую версию;
- `get_latest_version()` обращается к GitHub Releases;
- `get_application_dir()` возвращает каталог исходного проекта или exe-файла;
- `RotateIconAnimation` поворачивает стрелку расширенного раздела;
- `WinDialog` показывает результаты проверки обновлений и ошибки.

`packaging.version.Version` используется для корректного сравнения тегов
версий после удаления возможного префикса `v`.

## Класс `_MiniDropdown`

Класс наследует `QComboBox`, но скрывает выбранное значение под собственным
`QLabel` и размещает иконку справа. Оба накладных элемента пропускают события
мыши к настоящему combo box.

### Состояние

| Атрибут | Назначение |
| --- | --- |
| `_icon_size` | Размер иконки в пикселях |
| `_icon_label` | Накладной label с иконкой |
| `_value_label` | Накладной label с текущим текстом |

## Справочник методов `_MiniDropdown`

### `__init__(icon_path: str, icon_size: tuple[int, int]) -> None`

Создаёт combo box и два дочерних label поверх него.

**Параметры:**

- `icon_path` — путь к изображению стрелки;
- `icon_size` — ширина и высота иконки.

**Возвращаемое значение:** отсутствует.

**Изменение состояния:** сохраняет размер, создаёт `_icon_label` и
`_value_label`.

**Побочные эффекты:** загружает иконку, подключает `currentTextChanged` к
`_show_selected_value()`.

### `_show_selected_value(value: str) -> None`

Записывает `value` в накладной label выбранного значения и поднимает оба
накладных элемента над нативным combo box.

**Изменение состояния:** меняет текст `_value_label`.

**Побочные эффекты:** вызывает `_raise_overlays()`.

### `_raise_overlays() -> None`

Вызывает `raise_()` для иконки и значения. Метод не меняет данные, но
восстанавливает правильный порядок отрисовки дочерних виджетов.

### `resizeEvent(event) -> None`

После стандартной обработки resize-события размещает иконку справа по центру,
а label значения растягивает на оставшуюся ширину.

**Параметры:** `event` — событие изменения размера от Qt.

**Изменение состояния:** меняет геометрию `_icon_label` и `_value_label`.

**Побочные эффекты:** повторно поднимает накладные элементы.

### `showPopup() -> None`

Открывает стандартный popup combo box, затем задаёт popup и его представлению
ширину самого элемента.

**Изменение состояния:** меняет ширину popup-окна и view.

**Побочные эффекты:** поднимает popup и после этого накладные элементы.

**Важные условия:** это переопределение стандартного Qt-метода с именем в
camelCase; переименовывать его в snake_case нельзя.

## Класс `SettingsPage`

### Состояние страницы

| Атрибут | Назначение |
| --- | --- |
| `on_back` | Callback возврата к главной странице |
| `_advanced_expanded` | Открыт ли блок дополнительных настроек |
| `translations_select` | Выбор `RU` или `EN` |
| `gaze_toggle` | Включение проверки глаз |
| `glasses_toggle` | Использование порога для очков |
| `advanced_content` | Скрываемое содержимое расширенного блока |
| `_advanced_icon_animation` | Анимация поворота стрелки |

Подписи действий и настроек также сохраняются в атрибутах, чтобы
`retranslate_ui()` мог менять их после смены языка.

## Конструктор и жизненный цикл `SettingsPage`

Страница создаётся один раз при запуске приложения. Конструктор строит
фиксированный заголовок и прокручиваемую область, загружает значения
конфигурации, подключает обработчики и скрывает расширенное содержимое.

Изменение переключателя или списка записывается сразу. Возврат на страницу не
перечитывает конфигурацию заново, потому что экземпляр и его виджеты
сохраняются в `QStackedWidget`.

## Справочник методов `SettingsPage`

### `__init__(on_back) -> None`

Создаёт страницу, информационный блок проекта, действия, язык, два
переключателя и расширенный раздел.

**Параметры:**

- `on_back` — callback без аргументов для кнопки возврата.

**Возвращаемое значение:** отсутствует.

**Изменение состояния:** создаёт все виджеты и устанавливает
`_advanced_expanded = False`.

**Побочные эффекты:** читает конфигурацию при создании переключателей и списка,
подключает сигналы, загружает графические ресурсы, создаёт анимацию и вызывает
`retranslate_ui()`.

### `_add_action(layout, icon_path, icon_size, callback) -> QLabel`

Добавляет строку действия: текст слева, растяжение и иконную кнопку справа.

**Параметры:**

- `layout` — вертикальный layout, в который добавляется строка;
- `icon_path` — путь к иконке кнопки;
- `icon_size` — `(width, height)`;
- `callback` — обработчик нажатия без аргументов.

**Возвращаемое значение:** `QLabel`, чтобы вызывающий код позднее установил или
перевёл текст.

**Побочные эффекты:** создаёт виджеты, подключает `button.clicked` и изменяет
переданный layout.

### `_add_toggle(layout: QVBoxLayout, config_key: str) -> tuple[QLabel, QCheckBox]`

Добавляет строку настройки с подписью и checkbox.

**Параметры:**

- `layout` — контейнер строки;
- `config_key` — ключ, который читается и обновляется в конфигурации.

**Возвращаемое значение:** кортеж `(label, toggle)`.

**Изменение состояния:** начальное состояние checkbox берётся из
`load_config()` и преобразуется в `bool`.

**Побочные эффекты:** подключает `toggled` к lambda, вызывающей
`update_config(**{config_key: checked})`.

**Важные условия:** ключ не проверяется по списку допустимых настроек. Опечатка
создаст новый ключ в JSON.

### `_add_advanced_settings(layout, icon_path, icon_size, callback) -> tuple[QLabel, QPushButton, QFrame, QLabel]`

Создаёт единую карточку с заголовком, кнопкой-стрелкой и скрываемым содержимым.

**Параметры:** layout назначения, путь и размер иконки, callback раскрытия.

**Возвращаемое значение:** `(label, button, content, content_label)` для
последующего управления текстом, видимостью и анимацией.

**Побочные эффекты:** добавляет карточку в переданный layout и подключает
кнопку.

### `_add_mini_dropdown_menu(layout, values, icon_path, icon_size, config_key) -> tuple[QLabel, QComboBox]`

Создаёт строку с подписью и `_MiniDropdown`, заполняет варианты и выбирает
сохранённое значение.

**Параметры:**

- `layout` — вертикальный layout;
- `values` — непустая последовательность допустимых строк;
- `icon_path`, `icon_size` — ресурс и размер стрелки;
- `config_key` — ключ конфигурации.

**Возвращаемое значение:** `(label, dropdown)`.

**Изменение состояния:** устанавливает сохранённое значение, если оно входит в
`values`; иначе использует первый вариант.

**Побочные эффекты:** читает конфигурацию, добавляет виджеты и подключает
сохранение через `_save_dropdown_selection()`.

**Ошибки:** вызывает `ValueError`, если `values` пуст или один из размеров
иконки неположителен.

### `_save_dropdown_selection(config_key: str, value: str, allowed_values: Sequence[str]) -> None`

Сохраняет выбранное значение, только если оно присутствует в
`allowed_values`.

**Побочные эффекты:** при допустимом значении вызывает `update_config()`.

**Важные условия:** недопустимое значение игнорируется без сообщения
пользователю.

### `_change_language(language: str) -> None`

Получает текущий экземпляр `QApplication` и передаёт его вместе с выбранным
кодом в `set_application_language()`.

**Побочные эффекты:** может установить или удалить `QTranslator`, что приводит
к рассылке `LanguageChange` существующим виджетам.

**Важные условия:** если экземпляр приложения отсутствует, метод ничего не
делает. Сохранение значения уже выполняется отдельным обработчиком dropdown.

### `_create_separator() -> QFrame`

Создаёт горизонтальную линию `QFrame` высотой один пиксель и возвращает её.
Внешнее состояние страницы не изменяет до добавления результата в layout.

### `update_checker() -> None`

Синхронно запрашивает последнюю версию и сравнивает её с `__version__`.

**Алгоритм:**

1. вызывает `get_latest_version()`;
2. удаляет начальный `v` у обоих значений;
3. преобразует строки в `Version`;
4. при наличии новой версии показывает диалог с кнопкой страницы обновления;
5. иначе сообщает, что установлена последняя версия.

**Побочные эффекты:** выполняет сетевой запрос, пишет исключения в лог и всегда
показывает `WinDialog` с результатом или ошибкой.

**Ошибки:** любые исключения, включая сетевые ошибки и некорректную строку
версии, перехватываются общим `except Exception` и отображаются пользователю.

### `open_folder() -> None`

Открывает путь `get_application_dir()` через
`QDesktopServices.openUrl(QUrl.fromLocalFile(...))`.

**Побочные эффекты:** передаёт операционной системе запрос на открытие
проводника. Открывается каталог программы, а не пользовательский каталог
настроек и медиа.

### `open_github() -> None`

Открывает `https://github.com/DXlol112/LockedFace` во внешнем браузере через
`QDesktopServices`.

### `advanced_settings_open() -> None`

Инвертирует `_advanced_expanded`, показывает или скрывает `advanced_content` и
поворачивает стрелку к `90°` или `0°`.

**Побочные эффекты:** изменяет layout страницы и запускает
`RotateIconAnimation`.

### `_set_advanced_settings_text(title: str, content: str) -> None`

Устанавливает заголовок расширенного блока и текст его содержимого.

**Параметры:** `title` и `content` уже должны быть переведены вызывающим кодом.

### `retranslate_ui() -> None`

Обновляет версию, названия действий, подпись языка, подписи двух переключателей
и тексты расширенного раздела.

**Изменение состояния:** меняет тексты label, не меняя значения checkbox,
dropdown и флага раскрытия.

**Важные условия:** версия подставляется заменой маркера `1.0.0` в переведённой
строке.

### `changeEvent(event: QEvent) -> None`

При `QEvent.Type.LanguageChange` вызывает `retranslate_ui()`, затем передаёт
событие базовому QWidget.

## Сигналы, callbacks и поток данных

```text
gaze_toggle.toggled(bool)
    → update_config(gaze_enabled=bool)

glasses_toggle.toggled(bool)
    → update_config(glasses_enabled=bool)

translations_select.currentTextChanged(code)
    ├── _save_dropdown_selection(...)
    └── _change_language(code)
        → set_application_language(...)
        → LanguageChange
        → retranslate_ui()
```

Кнопки действий напрямую вызывают `update_checker()`, `open_folder()`,
`open_github()` и `advanced_settings_open()`.

## Как изменять и расширять модуль

### Добавить boolean-настройку

1. Добавьте значение по умолчанию в конфигурацию.
2. В конструкторе вызовите `_add_toggle(layout, "new_key")`.
3. Сохраните возвращённые label и checkbox в атрибутах.
4. Установите переводимый текст label в `retranslate_ui()`.
5. Прочитайте новый ключ там, где он влияет на поведение приложения.

### Добавить настройку с ограниченным набором значений

Используйте `_add_mini_dropdown_menu()`. Передайте непустой набор значений и
положительный размер иконки. Если значение требует немедленного применения,
подключите отдельный обработчик наподобие `_change_language()`.

### Добавить действие

Создайте метод-обработчик и вызовите `_add_action()` в конструкторе. Полученный
label сохраните и заполняйте в `retranslate_ui()`.

### Наполнить дополнительные настройки

Сейчас внутри `advanced_content` находится только placeholder. Для реальных
элементов добавляйте виджеты в layout, созданный в `_add_advanced_settings()`,
или расширьте возвращаемый контракт метода так, чтобы вызывающий код получал
этот layout. Не смешивайте состояние раскрытия с сохраняемыми настройками.

### Изменить список языков

Нужно согласованно обновить значения dropdown, поддержку языка в
`script/core/i18n.py` и каталог перевода. Простого добавления строки в `values`
недостаточно.

## Связь со стилями

Страница использует `script/style/settings_page.qss`. Основные имена объектов:
`header_sett`, `back_btn`, `settings_scroll`, `settings_content`,
`text_settings`, `settings_btn`, `toggle_btn`, `mini_dropdown`,
`mini_dropdown_list`, `advanced_settings_card` и связанные имена расширенного
блока.

Иконка поворота задаётся в Python через `RotateIconAnimation`; QSS отвечает
только за внешний вид кнопки и карточки.

## Текущие ограничения

- Проверка обновлений выполняется синхронно в главном UI-потоке и может ждать
  сетевой timeout.
- Значения checkbox и dropdown читаются только при создании страницы.
- «Дополнительные настройки» пока содержат текст-заглушку.
- Dropdown имеет фиксированный размер `50 × 26`, а popup — фиксированную ширину.
- Ссылка на GitHub и URL обновления заданы непосредственно в коде.
- Типы callbacks вспомогательных методов частично не указаны.
