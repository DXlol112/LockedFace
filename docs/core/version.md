# Модуль `version.py`

## Назначение модуля

`script/core/version.py` определяет локальную версию по последнему Git-тегу и
запрашивает тег последнего опубликованного GitHub Release.

## Место в архитектуре

`__version__` показывается на главной странице и странице настроек.
`SettingsPage.update_checker()` вызывает `get_latest_version()`, а затем
сравнивает версии через `packaging.version.Version`.

## Константы и состояние модуля

### `LATEST_RELEASE_API_URL`

URL GitHub API:

```text
https://api.github.com/repos/DXlol112/LockedFace/releases/latest
```

### `__version__`

Вычисляется как `get_version()` непосредственно при импорте модуля. Значение не
обновляется автоматически, если Git-состояние изменилось после импорта.

## Справочник функций

### `get_version() -> str`

Запускает Git в корне репозитория и получает последний достижимый тег.

**Команда:**

```text
git describe --tags --abbrev=0
```

**Возвращаемое значение:** непустой stdout без пробелов по краям либо строка
`"unknown"`.

**Побочные эффекты:** создаёт дочерний процесс Git. stderr подавляется.

**Обработка ошибок:** `FileNotFoundError`, `CalledProcessError` и `OSError`
превращаются в `"unknown"`.

**Важные условия:** функция возвращает последний тег, а не hash коммита и не
обязательно тег, точно соответствующий текущему состоянию файлов.

### `get_latest_version(timeout: float = 5.0) -> str`

Запрашивает объект последнего release через GitHub REST API.

**Параметры:** `timeout` — timeout `urlopen()` в секундах.

**Запрос:** передаёт заголовки `Accept`, `User-Agent` и версию GitHub API.

**Возвращаемое значение:** непустой `tag_name` без пробелов по краям.

**Побочные эффекты:** выполняет синхронный сетевой запрос и разбирает JSON.

**Исключения:** сетевые ошибки, timeout и ошибки JSON не перехватываются.
Отсутствующий или некорректный `tag_name` вызывает `ValueError`.

### `get_lastest_verison(timeout: float = 5.0) -> str`

Compatibility alias со старой опечаткой в имени. Полностью делегирует вызов
`get_latest_version(timeout)` и возвращает или пробрасывает тот же результат.

Удалять alias без проверки внешних импортов нельзя: он экспортируется через
`script.core`.

## Поток проверки обновлений

```text
import version.py
    → get_version()
    → __version__

SettingsPage.update_checker()
    → get_latest_version()
    → GitHub API tag_name
    → Version(latest) > Version(current)
```

## Как изменять механизм версии

### Версия, встроенная в сборку

Если exe должен всегда показывать известную версию без Git, сформируйте модуль
с константой на этапе сборки или читайте package metadata. Затем оставьте Git
как fallback для разработки.

### Другой источник обновлений

Замените URL и адаптируйте проверку JSON. Сохраните контракт функции: вернуть
непустую строку тега или выбросить понятное исключение.

### Асинхронная проверка

Сетевой вызов следует вынести из главного UI-потока. Результат или ошибку нужно
вернуть через Qt-сигнал, а диалог создать в UI-потоке.

## Текущие ограничения

- При импорте запускается внешний процесс Git.
- В сборке без `.git` или Git в `PATH` локальная версия становится `unknown`.
- Проверка GitHub синхронная, не кешируется и зависит от сети.
- API URL и заголовки заданы непосредственно в модуле.
- Deprecated alias не помечен предупреждением и остаётся публичным.
