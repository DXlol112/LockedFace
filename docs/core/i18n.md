# Модуль `i18n.py`

## Назначение модуля

`script/core/i18n.py` управляет переводами Qt. Русский язык является исходным
языком строк в Python-коде, а английский загружается из скомпилированного
`.qm`-каталога.

## Место в архитектуре

При запуске `LockedFace.py` читает `translations_select` из конфигурации и
вызывает `set_application_language()`. Позже `SettingsPage` вызывает ту же
функцию при изменении dropdown.

Установка или удаление `QTranslator` приводит к событиям `LanguageChange`, а
UI-страницы обновляют тексты в своих `retranslate_ui()`.

## Зависимости и константы

| Имя | Значение | Назначение |
| --- | --- | --- |
| `TRANSLATIONS_DIR` | `"translations"` | Каталог переводов рядом с приложением |
| `TRANSLATION_PREFIX` | `"lockedface_"` | Префикс файлов `.qm` |
| `DEFAULT_LANGUAGE` | `"RU"` | Безопасный исходный язык |
| `SUPPORTED_LANGUAGES` | `{"RU", "EN"}` | Допустимые значения конфигурации |

`QLocale` предоставляет системную локаль, `QTranslator` загружает каталог, а
`get_application_dir()` находит ресурсы при запуске из исходников и сборки.

## Справочник функций

### `normalize_language(language: object) -> str`

Преобразует произвольный объект в строку верхнего регистра.

**Параметры:** `language` — значение конфигурации или UI.

**Возвращаемое значение:** нормализованный поддерживаемый код либо `"RU"`.

**Побочные эффекты:** отсутствуют.

**Важные условия:** пробелы не удаляются. Например, `" en "` считается
неподдерживаемым и превращается в `"RU"`.

### `install_translation(app: QApplication, locale: str | None = None) -> QTranslator | None`

Ищет, загружает и устанавливает наиболее подходящий `.qm`-каталог.

**Параметры:**

- `app` — активный `QApplication`;
- `locale` — явная локаль или `None` для `QLocale.system().name()`.

**Алгоритм:**

1. заменяет `-` на `_` в имени локали;
2. выделяет код языка до первого `_` и переводит его в нижний регистр;
3. формирует каталог `application_dir/translations/<language>`;
4. последовательно пробует полную локаль и короткий код без дубликатов;
5. для каждого кандидата загружает `lockedface_<candidate>`;
6. при успехе устанавливает translator в приложение и возвращает его.

**Возвращаемое значение:** установленный `QTranslator` либо `None`.

**Побочные эффекты:** читает файлы перевода, вызывает
`app.installTranslator()` и пишет результат в лог.

**Важные условия:** отсутствие каталога не является исключением. Русские
исходные строки продолжают отображаться.

### `set_application_language(app: QApplication, language: object) -> QTranslator | None`

Применяет поддерживаемый язык к уже работающему приложению.

**Параметры:** активное приложение и произвольное значение языка.

**Алгоритм и состояние:**

1. нормализует код;
2. если `app.language_code` уже совпадает, возвращает текущий translator;
3. удаляет прежний `app.translator`, если он существует;
4. для `EN` вызывает `install_translation(app, "en")`;
5. для `RU` оставляет translator равным `None`;
6. сохраняет `app.translator` и `app.language_code` как динамические атрибуты.

**Возвращаемое значение:** английский translator или `None`.

**Побочные эффекты:** меняет translators приложения, инициирует обновление
переводимых виджетов и пишет info/warning в лог.

## Поток смены языка

```text
SettingsPage: EN
    → update_config("user_settings", translations_select="EN")
    → set_application_language(app, "EN")
    → install_translation(app, "en")
    → translations/en/lockedface_en.qm
    → LanguageChange
    → UI.retranslate_ui()
```

## Как добавить язык

1. Добавьте код в `SUPPORTED_LANGUAGES`.
2. Создайте `translations/<code>/lockedface_<code>.ts` и скомпилированный
   `.qm`.
3. Добавьте код в UI выбора языка.
4. Обобщите условие в `set_application_language()`: текущая реализация
   загружает translator только для `EN`.
5. Включите каталог в сборку и проверьте `LanguageChange` на всех страницах.

## Текущие ограничения

- Фактически реализованы только `RU` и `EN`.
- Логика установки явно выделяет английский, а не любой язык кроме русского.
- Неудачная загрузка перевода не показывается пользователю в UI.
- Нормализация не удаляет пробелы и не поддерживает языковые aliases.
- Существующие диалоги без `changeEvent()` не меняют текст после смены языка.
