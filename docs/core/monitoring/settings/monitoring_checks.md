# Модуль `monitoring_checks.py`

## Назначение модуля

`script/core/monitoring/settings/monitoring_checks.py` содержит чистые проверки
результата MediaPipe: наличие лица, состояние глаз и положение головы.
Функции не открывают камеру, не управляют таймерами и не показывают окна.

## Место в архитектуре

`VideoThread.run()` передаёт `FaceMesh.process()` в
`run_detection_checks()`. Функция возвращает единый `DetectionStatus` и точки
первого лица. Статус затем обрабатывает `MonitoringTimers.should_show_alert()`.

## Зависимости

- `numpy.sqrt()` вычисляет евклидову дистанцию;
- `SensitivitySettings` предоставляет пороги;
- `LEFT_EYE_LANDMARKS` и `RIGHT_EYE_LANDMARKS` выбирают точки глаз;
- `Any` и `Sequence` позволяют работать с объектами результата MediaPipe без
  прямой зависимости типов.

## Dataclass `DetectionStatus`

```python
DetectionStatus(
    face_detected: bool,
    eyes_detected: bool,
    head_looking_forward: bool,
)
```

Класс неизменяемый (`frozen=True`) и использует slots.

| Поле | Значение `True` означает |
| --- | --- |
| `face_detected` | MediaPipe вернул landmarks хотя бы одного лица |
| `eyes_detected` | Проверка глаз разрешила продолжение |
| `head_looking_forward` | Нос находится внутри допустимой центральной области |

При отсутствии лица aggregate-функция возвращает
`DetectionStatus(False, False, True)`: нарушение фиксируется через лицо/глаза,
а отдельный таймер поворота головы не запускается.

## Справочник функций

### `get_face_landmarks(results: Any) -> Sequence[Any] | None`

Извлекает landmarks первого обнаруженного лица.

**Параметры:** объект результата MediaPipe или совместимый объект с атрибутом
`multi_face_landmarks`.

**Возвращаемое значение:** `faces[0].landmark` либо `None`, если атрибут
отсутствует или список пуст.

**Побочные эффекты:** отсутствуют.

**Исключения:** если непустой первый элемент не имеет `landmark`, ошибка
атрибута пробрасывается.

### `check_face(landmarks: Sequence[Any] | None) -> bool`

Возвращает `True`, когда значение landmarks не равно `None`.

Пустая, но не `None` последовательность считается обнаруженным лицом.
Побочные эффекты и исключения отсутствуют.

### `is_eye_open(landmarks, eye_indices, glasses_enabled, sensitivity=DEFAULT_SENSITIVITY) -> bool`

Проверяет один глаз по дистанции между двумя landmarks.

**Параметры:**

- `landmarks` — последовательность точек с координатами `x` и `y`;
- `eye_indices` — минимум два индекса;
- `glasses_enabled` — выбор обычного или более низкого порога;
- `sensitivity` — настройки чувствительности.

**Алгоритм:** вычисляет
`sqrt((x1-x2)^2 + (y1-y2)^2)` и сравнивает значение строго через `>` с
`eye_open_threshold` либо `eye_open_with_glasses_threshold`.

**Возвращаемое значение:** обычный Python `bool`.

**Побочные эффекты:** отсутствуют.

**Исключения:** неверные индексы, короткая последовательность или точки без
`x/y` приводят к стандартным исключениям и не перехватываются.

### `check_eyes(landmarks, gaze_enabled, glasses_enabled, sensitivity=DEFAULT_SENSITIVITY) -> bool`

Проверяет оба глаза, когда отслеживание включено.

**Возвращаемое значение:**

- `True` без вычислений, если `gaze_enabled == False`;
- иначе `True`, если открыт хотя бы один глаз.

**Побочные эффекты:** отсутствуют. Вызывает `is_eye_open()` дважды при активной
проверке.

**Важные условия:** алгоритм использует логическое `OR`, поэтому закрытие одного
глаза не считается нарушением.

### `is_head_turned_away(landmarks, sensitivity=DEFAULT_SENSITIVITY) -> bool`

Оценивает положение носа относительно границ лица.

**Используемые точки:** нос `4`, левая сторона `234`, правая сторона `454`,
верх `10`, низ `152`.

**Алгоритм:**

1. вычисляет ширину лица и горизонтальное положение носа;
2. вычисляет высоту лица и вертикальное положение носа;
3. проверяет оба отношения на попадание в замкнутый диапазон
   `[head_position_min_ratio, head_position_max_ratio]`;
4. возвращает инверсию результата.

**Возвращаемое значение:** `True`, если голова считается отвёрнутой.

**Особые случаи:** нулевая ширина или высота немедленно дают `True`.

**Исключения:** отсутствующие индексы или координаты не перехватываются.

### `check_head_position(landmarks, sensitivity=DEFAULT_SENSITIVITY) -> bool`

Возвращает инверсию `is_head_turned_away()`: `True` означает, что пользователь
смотрит вперёд.

Состояние не изменяет и дополнительных исключений не вводит.

### `run_detection_checks(results, gaze_enabled, glasses_enabled, sensitivity=DEFAULT_SENSITIVITY) -> tuple[DetectionStatus, Sequence[Any] | None]`

Объединяет все проверки одного кадра.

**Параметры:** результат FaceMesh, два UI-флага и настройки чувствительности.

**Возвращаемое значение:** `(status, landmarks)`.

**Алгоритм:**

1. получает точки первого лица;
2. при их отсутствии возвращает `(DetectionStatus(False, False, True), None)`;
3. иначе проверяет глаза и голову;
4. возвращает неизменяемый aggregate и исходную последовательность точек.

**Побочные эффекты:** отсутствуют.

## Поток проверки кадра

```text
FaceMesh result
    → get_face_landmarks
    ├── None → status(False, False, True)
    └── landmarks
        ├── check_eyes
        │   └── is_eye_open × 2
        └── check_head_position
            └── is_head_turned_away
```

## Как добавить новую проверку

1. Реализуйте чистую функцию, принимающую landmarks и настройки.
2. Добавьте поле результата в `DetectionStatus` либо создайте отдельный status,
   если изменение публичного контракта нежелательно.
3. Вызовите проверку из `run_detection_checks()`.
4. Определите, как `MonitoringTimers` должен реагировать на новое поле.
5. Добавьте порог в `SensitivitySettings`, если он нужен.

## Текущие ограничения

- Анализируется только первое найденное лицо.
- Глаз определяется двумя точками и простой дистанцией без калибровки.
- Состояние «открыт хотя бы один глаз» считается нормой.
- Положение головы оценивается только относительным положением носа.
- Нет защиты от неполных или несовместимых landmarks.
- Все проверки выполняются на каждом обработанном кадре.
